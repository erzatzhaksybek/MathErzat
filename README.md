# MATHERZAT — Live Quiz

Мұғалім басқаратын, оқушылар QR-кодпен әртүрлі телефоннан қосылатын онлайн тест платформасы.

## Қазір іске асырылған мүмкіндіктер

- Мұғалім мен оқушыға арналған бөлек кіру экрандары.
- Мұғалім құпиясөзі сервердегі `TEACHER_PASSWORD` айнымалысымен қорғалады.
- Мұғалім тест атауын, сұрақты, төрт жауап нұсқасын, дұрыс жауапты және қиындық деңгейін енгізеді.
- Әр сұрақтың таймері: оңай — 30 секунд, орташа — 40 секунд, қиын — 45 секунд.
- Мұғалім тест бөлмесін ашады; жүйе 6 таңбалы код пен QR-код жасайды.
- Оқушы QR-ды сканерлеп, аты-жөнін енгізіп қосылады. QR сілтемесі бөлме кодын автоматты толтырады.
- Оқушылар мен мұғалімнің экрандары Socket.IO арқылы синхрондалады; мектеп желісі WebSocket-ті шектесе, 4 секундтық polling қосалқы арна ретінде жұмыс істейді.
- Оқушы жауапты өз телефонынан таңдап, бір рет жібереді. Қабылданған жауапты өзгерте алмайды.
- Уақыт аяқталса, сервер жауапты қабылдамайды; жауап бермеген оқушы бұл сұрақтан 0 ұпай алады.
- Мұғалім таймер бітуін күтпей-ақ кез келген уақытта келесі сұрақты аша алады.
- Оқушыларды екі топқа кездейсоқ бөлу, әр оқушының ұпайын және топтың орташа ұпайын есептеу, рейтинг көрсету.
- Тест аяқталғаннан кейін оқушы өз жауабын және дұрыс жауапты көре алады.
- Дизайн телефонға, планшетке және компьютерге бейімделген.

## 1. Жергілікті компьютерде тексеру

Node.js 20 немесе одан жаңа нұсқа керек.

```bash
npm install
cp .env.example .env
npm start
```

Содан кейін браузерден `http://localhost:3000` ашыңыз.

Supabase бапталмаған жағдайда сайт жергілікті demo режимінде ашылады. Бұл режимде дерек тек сервер жадына сақталады; сервер қайта қосылса, тест бөлмелері жоғалады. Мұғалімнің жергілікті demo құпиясөзі: `matherzat-demo-2026`. Интернетке жариялар алдында оны міндетті түрде өзгертіңіз.

## 2. Supabase дерекқорын дайындау

1. Supabase сайтында жаңа Free жоба ашыңыз.
2. Жобаның SQL Editor бөліміне кіріп, осы архивтегі `schema.sql` файлының толық мазмұнын орындаңыз.
3. Project Settings → API бөлімінен Project URL және `service_role` кілтін көшіріңіз.
4. `service_role` кілтін ешқашан браузерге, HTML/JavaScript файлына немесе ашық репозиторийге салмаңыз. Ол тек сервердің Environment Variables бөлімінде тұруы керек.

## 3. Render-ге жариялау

Бұл жоба статикалық сайт емес: QR қосылымы, мұғалімнің басқаруы және live синхрондау үшін Node.js сервері жұмыс істеуі керек. Сондықтан сайт пен сервер бір Render Web Service ретінде жарияланады, ал деректер Supabase-та сақталады.

1. `MATHERZAT` папкасының ішіндегі файлдарды GitHub репозиторийіне жүктеңіз.
2. Render ішінде **New → Web Service** таңдап, репозиторийді қосыңыз.
3. Build Command: `npm install`.
4. Start Command: `npm start`.
5. Environment Variables бөліміне мына мәндерді қосыңыз:
   - `NODE_ENV` = `production`
   - `SUPABASE_URL` = Supabase Project URL
   - `SUPABASE_SERVICE_ROLE_KEY` = Supabase `service_role` кілті
   - `TEACHER_PASSWORD` = өзіңіз орнататын ұзын, құпия мұғалім құпиясөзі
   - `SESSION_SECRET` = кездейсоқ, ұзын құпия жол (кемінде 32 таңба)
6. Deploy аяқталған соң Render берген `https://...onrender.com` мекенжайын ашыңыз.
7. Алғашқы тексеруді екі құрылғыдан жасаңыз: біреуінен мұғалім ретінде кіріп тест ашыңыз, екіншісінен QR сканерлеңіз.

`render.yaml` файлы Render Blueprint арқылы бастапқы баптауды жеңілдетеді. Құпия айнымалыларды Render панелінде өзіңіз енгізесіз.

## 4. Маңызды ескертпелер

- Бұл ZIP дайын бастапқы код пен жариялауға арналған конфигурацияны қамтиды. Оны нақты интернет-мекенжайына өз бетімше жариялау үшін сіздің GitHub/Render/Supabase аккаунттарыңызға кіру рұқсаты қажет; бұл архивке аккаунт құпиялары енгізілмеген.
- Render-дің тегін веб-қызметі 15 минут кіріс трафик болмаса ұйқы режиміне кетеді; келесі ашылуы шамамен 1 минут алуы мүмкін. Supabase Free жобасы бір апта белсенділік болмаса уақытша тоқтатылуы мүмкін. Тегін жоспарлардың лимиттері өзгеруі мүмкін.
- Қазіргі сессиялар сервер жадысында сақталады. Сервер қайта іске қосылса, мұғалім мен оқушылар қайта кіреді, бірақ Supabase-та сақталған тест пен нәтижелер жоғалмайды.
- Тест бөлмесінің коды тест атауын білмейтін басқа адамға да берілуі мүмкін. QR мен кодты тек өз сыныбыңызға таратыңыз.
- Нәтижелер әр дұрыс жауапқа 1 ұпайдан есептеледі. Жауап берілмеген сұраққа 0 ұпай беріледі.
